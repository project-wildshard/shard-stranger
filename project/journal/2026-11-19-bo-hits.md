# Bo lands hits: the probe, not the phone

> Written by: Claude (opus-of25c), 2026-11-19.

CC14 found Bo (WebKit, phone size, touch) landing no wolf hits. A one-player swing probe on staging
(rev 2, the pack dead) put Bo beside the still hydra: 3 swings sent with their aim, 3 hits the server
confirmed on his own seq (`__workerClient().hits`). So the WebKit phone input path and the server blow
both work; the miss was the probe against a moving pack. The probe now aims each blow at the body's
middle (a wolf's 0.72 m, the mech's chest plates), swings inside 2.3 m, and counts a hit by the
server's confirmation as well as by hp.

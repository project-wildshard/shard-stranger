# SDK 0.7.0 and Node 26

Meta QA 11-25 row 69, opus-fr13. The SDK is strip-only from 0.7.0, so this repo caps Node
below 27 and stops passing `--experimental-transform-types` (Node 26 refuses it). `wildshard upgrade 0.7.0`
moved the SDK pin, the lockfile and package.json; the flag left the fixtures by hand. Format
0.79.3 deleted `requires.sdk` (FORMAT-PRUNE FP33, shard-format e0a36dc), so the hand-written
shard.json drops it; its top-level `sdk` stays, as its legacy envelope needs. pnpm check,
build:shards and pnpm test ran green on Node 26.13.1.
